# Support

Use GitHub Issues for reproducible bugs and focused feature proposals. Include the Frame package versions, Node.js and
PostgreSQL versions, relevant logs with secrets removed, and a minimal reproduction when possible.

Questions, implementation consulting, deployment operations, upgrade execution, and response-time commitments are not
guaranteed through the public issue tracker. LingcooTech may offer these separately as commercial services.

Security issues must follow [SECURITY.md](SECURITY.md), not a public issue. Private industry applications and customer
deployments use their own support channel.
