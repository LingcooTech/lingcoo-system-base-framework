# Security Policy

## Supported versions

Before `1.0`, security fixes are provided for the latest published minor line. Older `0.x` lines may require an upgrade
to receive a fix. Release notes identify any exceptional support window.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/LingcooTech/lingcoo-system-base-framework/security/advisories/new)
and include:

- the affected package and version;
- reproduction steps or a minimal proof of concept;
- the expected security impact;
- any known workaround.

Maintainers aim to acknowledge a complete report within three business days, validate severity, coordinate a fix and
publish an advisory. Please avoid accessing data that is not yours, disrupting services, or publicly disclosing the
issue before a fix is available.

Security reports cover the open-source Frame packages and reference application. Vulnerabilities in a private
LingcooTech product or customer deployment should be reported through that product's support channel.
