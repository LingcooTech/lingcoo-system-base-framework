# @lingcootech/frame-web

Composable React 19 public-site shell with routing, SEO, sitemap, account flows, and landing block contracts.

```bash
npm install @lingcootech/frame-web
```

See the [frontend foundation](https://github.com/LingcooTech/lingcoo-system-base-framework/blob/main/docs/frontend-foundation.md)
for integration guidance.
