# @lingcootech/frame-design-tokens

Semantic base, Admin, and public-site CSS tokens for Lingcoo Frame applications.

```bash
npm install @lingcootech/frame-design-tokens
```

Import `@lingcootech/frame-design-tokens/base.css`, `admin.css`, or `public.css` through the package exports.
