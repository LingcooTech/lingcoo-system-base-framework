# @lingcootech/frame-extension-sdk

Browser-safe manifests and typed Server, Worker, Migration, Admin, and Web extension contracts for Lingcoo Frame.

```bash
npm install @lingcootech/frame-extension-sdk
```

See the [extension guide](https://github.com/LingcooTech/lingcoo-system-base-framework/blob/main/docs/extension-development.md)
for composition and package-boundary rules.
