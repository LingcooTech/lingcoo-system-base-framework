# @lingcootech/frame-ui

Browser-safe React 19 primitives shared by Frame Admin and public applications.

```bash
npm install @lingcootech/frame-ui
```

Components are available through documented subpath exports. See the
[package contracts](https://github.com/LingcooTech/lingcoo-system-base-framework/blob/main/docs/package-contracts.md).
