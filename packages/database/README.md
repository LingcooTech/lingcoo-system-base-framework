# @lingcootech/frame-database

PostgreSQL/Drizzle schema, database client, and namespaced migration runtime for Lingcoo Frame.

```bash
npm install @lingcootech/frame-database
```

Migration IDs and applied SQL are immutable. See the
[package contracts](https://github.com/LingcooTech/lingcoo-system-base-framework/blob/main/docs/package-contracts.md)
and [migration ADR](https://github.com/LingcooTech/lingcoo-system-base-framework/blob/main/docs/adr/0003-migration-identity-and-compatibility.md).
