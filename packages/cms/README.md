# @lingcootech/frame-cms

Optional first-party CMS extension for every Frame runtime surface, including migrations and default Admin/Web pages.

```bash
npm install @lingcootech/frame-cms
```

See the [CMS documentation](https://github.com/LingcooTech/lingcoo-system-base-framework/blob/main/docs/cms-lite.md)
and [first-party extension boundary](https://github.com/LingcooTech/lingcoo-system-base-framework/blob/main/docs/first-party-extensions.md).
