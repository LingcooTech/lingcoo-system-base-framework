# 系统设置与审计中心

系统设置是可在线调整的非敏感框架参数，不是任意键值仓库。新增设置必须先在
`src/modules/settings/registry.ts` 登记类型、默认值和说明，接口拒绝未知键。数据库连接、JWT 密钥和
Provider 凭据不属于这里：前两者由部署环境注入，后者由外部集成模块加密管理。

每次设置变更会更新当前值、递增版本并追加一条不可变历史，同时写入 `system.setting_updated` 审计事件。
管理后台可查看版本值、操作者、时间和变更原因。

所有基础模块通过 `recordAuditEvent` 写入统一审计协议：`action` 使用
`领域.资源_动作`，`resourceType` 和 `resourceId` 指向受影响资源，`metadata` 只保存帮助追踪的安全上下文。
密码、令牌、邮件内容、模型提示词与回复、Provider 密钥禁止进入审计元数据。审计中心支持分页及动作、
资源类型、资源 ID、操作者和时间范围过滤，访问由 `audit.read` 独立控制。
