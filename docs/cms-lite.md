# 轻量内容中心

`cms` 提供剔除行业业务后的页面与文章基础，正文第一阶段固定使用 Markdown。

## 已包含

- `page` 与 `article` 两种基础内容类型。
- 草稿、已发布、已归档状态，以及登录态草稿预览。
- 每次保存生成不可变版本，发布与归档写入审计事件。
- 封面图和社交分享图使用 Asset ID，并登记资产引用。
- 复用 Metadata 的分类与标签，注册到统一搜索。
- 公共页面、文章详情和文章列表使用安全 Markdown 渲染。

## 明确不包含

产品、课程等行业内容类型，任意动态字段模型，复杂审批流和自由拖拽页面设计器均不属于 CMS Lite。领域模块可以在这些稳定边界之上扩展自己的内容区块。
