# 轻量内容中心

`cms` 提供剔除行业业务后的页面与文章基础，正文第一阶段固定使用 Markdown。

## 已包含

- `page` 与 `article` 两种基础内容类型。
- 草稿、已发布、已归档状态，以及登录态草稿预览。
- 支持指定带时区的未来时间发布；计划写入持久化任务，Worker 执行前会再次核对当前计划。
- 每次保存生成不可变版本，发布与归档写入审计事件。
- 封面图和社交分享图使用 Asset ID，并登记资产引用。
- 复用 Metadata 的分类与标签，注册到统一搜索。
- 公共页面、文章详情和文章列表使用安全 Markdown 渲染。
- 公共文章列表提供服务端分页、总数与页数，前台复用共享 Pagination。
- 前台内容渲染、文章卡片、列表、空状态、封面图、详情布局和面包屑均为独立组件。
- 已发布页面和文章自动进入 Sitemap；草稿预览和系统页面统一禁止索引。
- 编辑器提供搜索结果与社交分享卡片预览，优先使用内容 SEO 字段和分享图，再回退到品牌配置。
- 管理员可以维护站内 301/302 重定向。来源必须是无查询参数、无锚点的站内绝对路径，目标只允许
  站内路径；服务会拒绝重复来源、自跳转和重定向循环。

## 发布计划

设置计划后，已发布内容会先回到草稿状态，并在目标时间重新发布。重新设置或取消计划不会破坏已经
进入队列的旧任务；旧任务执行时发现时间戳已变化会安全跳过。手动发布、撤回或归档都会清除当前计划。

定时发布复用 `job_runs` 和现有 Worker，不增加 Redis 等运行依赖。生产环境必须同时运行 API、Worker，
并在部署时执行 `0011_cms_workflow.sql`。

## URL 重定向

重定向只在真实 API、静态文件和已注册路由都未匹配时解析，因此不会覆盖现有系统入口。API 返回真实
HTTP `301` 或 `302` 及 `Location` 响应头，不依赖前端脚本跳转。目标限制为站内路径，避免将后台配置
变成开放重定向入口。

## 明确不包含

产品、课程等行业内容类型，任意动态字段模型，复杂审批流和自由拖拽页面设计器均不属于 CMS Lite。
领域模块可以在这些稳定边界之上扩展自己的内容区块。
