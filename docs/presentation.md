# 品牌与站点呈现

`presentation` 管理系统在管理后台和公共站点中的通用身份，不承载行业内容或营销页面业务。

## 能力边界

- 单一默认品牌档案，包含名称、简称、标语、品牌色、联系方式、SEO、导航和页脚基础字段。
- Logo、Favicon 和分享图只保存 `Asset ID`，且必须引用已启用的公开图片资产。
- 每次保存生成不可变版本并写入审计日志；资产引用同步登记到 `storage_asset_references`。
- `/api/presentation` 是权限保护的管理接口；`/api/public/presentation` 只提供可公开的呈现数据。
- 管理后台只采用名称与 Logo，避免任意品牌色破坏管理界面的可用性；公共站点可应用完整品牌色。
- 公共 SiteShell 统一读取 Logo、名称、标语、头部导航、页脚链接、联系方式、版权和备案信息；桌面与
  移动导航不维护两份配置。
- 顶部导航和页脚链接在管理后台中支持新增、编辑、删除与排序，数组顺序就是公共站点展示顺序。

具体行业的首页区块、商品、课程、活动和内容工作流不进入本模块，后续由 CMS 或领域模块提供。
