# 账号自服务与安全中心

账号安全能力属于身份内核，不定义教师、买家、员工或会员等行业资料。

## 安全链接

`auth_security_challenges` 支持 `password_reset`、`email_verification` 和
`account_invitation`。浏览器收到 256 位随机令牌，数据库只保存 SHA-256 摘要；令牌有明确有效期，
消费后立即失效，同一账号同一用途的新请求会使旧链接失效。

密码找回始终返回相同的 `202` 响应，不暴露邮箱是否存在。请求端同时受到独立频率限制。

## 邮件投递

安全邮件复用已启用的 SMTP Provider 和通知 Worker。带有原始令牌的邮件正文使用
`SETTINGS_ENCRYPTION_KEY` 进行 AES-256-GCM 加密，只把密文写入投递记录；通知正文、审计日志和
Job Payload 均不保存明文令牌。Worker 解密后调用 SMTP，并沿用重试、死亡任务和投递记录。

邀请邮件使用品牌设置中的 `publicUrl` 生成可信链接。生产环境如果缺少公共地址、加密密钥或可用
SMTP，管理员邀请会明确失败；忘记密码接口仍保持统一响应。

## 个人资料与会话

基础资料只包含显示名称、邮箱验证时间和头像 Asset ID。头像必须是已启用的公开图片，并登记
`account / avatarAssetId` 资产引用。账号可以查看最近会话、撤销其他设备、修改密码和查询自己的
认证审计记录；不能读取其他账号的会话。

开放注册不属于本模块。具体系统可以选择邀请制、领域注册流程或完全关闭公共账号入口。
